⚡ 1분 퀵 스타트 (Quick Start)

설치 후 프로젝트의 어떤 React 화면이든 다음과 같이 컴포넌트를 마운트하십시오.

NetworkDashboard.tsx 
import React from 'react';
import { GeoTopologyViewer } from 'geotopology';
import 'geotopology/dist/style.css'; // 라이브러리 전용 다크 글래스모피즘 스타일

export function NetworkDashboard() {
  return (
    <div style={{ width: '100vw', height: '100vh', overflow: 'hidden' }}>
      <GeoTopologyViewer
        onNodeSelect={(node) => {
          console.log('선택된 장비/국사:', node);
        }}
      />
    </div>
  );
}

🔧 GeoTopologyViewer Props API 명세

Prop 이름 타입 기본값 설명
nodes NetworkNode[] 기본 714대 장비 사용자 정의 관제 대상 장비/노드 데이터셋
edges NetworkEdge[] 기본 983개 회선 사용자 정의 백본/전송망 광회선 데이터셋
initialMapStyle MapStyleType 'OFFLINE_PMTILES_DARK' 초기 지도 스타일 (오프라인 벡터, OSM, 위성 등)
initial3DMode boolean true 초기 3D 피치 각도 및 실린더 타워 활성화
showNav boolean true 상단 옴니서치 및 장애 시뮬레이션 툴바 표시
showDashboard boolean true 좌측 알람 통계, 이벤트, 장비 리스트 대시보드 표시
showLegend boolean true 좌측 하단 3D 범례(장비 종류, 케이블 색상) 표시
showRightOverlay boolean true 우측 지도 테마 및 백본/경계선 레이어 온/오프 표시
onNodeSelect (node) => void undefined 노드 클릭 시 호출되는 이벤트 콜백 함수

📡 REST / SNMP / WebSocket 실시간 데이터 연동

자체 백엔드 API에서 주기적으로 수신한 노드 및 링크 데이터를 Props로 주입하면, 내부 상태가 자동으로 리렌더링되어 실시간 모니터링이 수행됩니다.

LivePollingExample.tsx 
import React, { useState, useEffect } from 'react';
import { GeoTopologyViewer, type NetworkNode, type NetworkEdge } from 'geotopology';
import 'geotopology/dist/style.css';

export function LiveOpsViewer() {
  const [nodes, setNodes] = useState([]);
  const [edges, setEdges] = useState([]);

  useEffect(() => {
    async function fetchLiveTopology() {
      const [nodeData, edgeData] = await Promise.all([
        fetch('/api/v1/topology/nodes').then(r => r.json()),
        fetch('/api/v1/topology/edges').then(r => r.json())
      ]);
      setNodes(nodeData);
      setEdges(edgeData);
    }

    fetchLiveTopology();
    const interval = setInterval(fetchLiveTopology, 5000); // 5초 폴링
    return () => clearInterval(interval);
  }, []);

  return <GeoTopologyViewer nodes={nodes} edges={edges} />;
}

💾 100% 폐쇄망 오프라인 (Air-Gapped) 설정

국가 중요 시설, 금융망, 국방망 등 외부 인터넷이 단절된 환경에서는 public/korea.pmtiles (73MB) 파일만 정적 자원 서버에 올려두면 타일 CDN 호출 없이 100% 로컬에서 동작합니다.

오프라인 모드 설정 
<GeoTopologyViewer
  initialMapStyle="OFFLINE_PMTILES_DARK" // 기본값 (100% 완전 로컬 구동)
/>

⚡ Next.js (SSR) 통합 가이드

Next.js의 서버 사이드 렌더링(SSR) 환경에서는 next/dynamic을 사용해 클라이언트 전용으로 마운트합니다.

app/monitoring/page.tsx (Next.js App Router) 
'use client';

import dynamic from 'next/dynamic';
import 'geotopology/dist/style.css';

const GeoTopologyViewer = dynamic(
  () => import('geotopology').then(mod => mod.GeoTopologyViewer),
  { ssr: false, loading: () => <div style={{ color: '#fff', padding: 20 }}>3D 관제 엔진 로딩 중...</div> }
);

export default function MonitoringPage() {
  return (
    <div style={{ width: '100vw', height: '100vh' }}>
      <GeoTopologyViewer />
    </div>
  );
}
